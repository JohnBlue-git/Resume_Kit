# Inbox

Drop raw material here: meeting notes, a commit summary, an interview reflection, a pasted
performance review, a JD you're applying to. Any language, any format (`.md`, `.txt`).

Nothing here is read by the build. Ask Claude to "process the inbox" (skill: resume-kit-record):
it proposes bullets / facts / skills as YAML diffs, you approve, and the processed file moves
to `content/inbox/done/`.

Suggested file name: `YYYY-MM-DD-topic.md`.
